# Who is doing what

Several agents work on Prosio, from more than one maker, and they cannot send each other messages. This file is how each knows what the others are doing: read it before you start, write your row before you edit anything, and move it to the history when you hand over. Gio reads it too.

## How to use it

1. **Before you start**, read **Current work** below, then run `git status` and `git worktree list`. If a row (or someone's uncommitted change) already has a file you need, do not edit it: tell Gio which file and whose row, and wait.
2. **Write your row** before your first edit: who you are (agent and model), the slice, the files or areas, the branch or folder, since when, the status, the next step. Change it when the scope changes.
3. **The main folder, `/Users/gio/Projects/prosio_game`, is Gio's and the dev session's.** The dev session works there, where Gio runs his workbench and sees its changes swapped in live (Gio, 2026-11-26). **Every other agent works on a branch in a git worktree of its own**:

   ```bash
   git worktree add ../prosio_game_SLICE -b SLICE
   ```

   Commit there, small and often. Only Gio says when a branch is merged into `main` and pushed; nobody force-pushes or rewrites published history.
4. **A workbench you start** uses its own folder and takes no keys or clicks, so it neither shares Gio's command file nor catches what he types: `WORKBENCH_OUT=build/workbench_YOURNAME WORKBENCH_UNFOCUSED=1 tools/workbench.sh` (README, "The workbench"). Only one workbench runs to a folder; a second says so and stops.
5. **Before you hand over**, `tools/check.sh` must pass (it prints PASS or FAIL for every rule). Then move your row to **Handoff history** with the date: what landed (commits and branch), how you checked it, what nobody has verified (on screen, by hand), and the next step.
6. **Decisions** are in `docs/plans/`: one file to a brief, each starting with a status line (proposed, agreed, built). They are the record of what Gio decided; a brief there is what to build. If what you find contradicts one, say so to Gio rather than guessing.
